Open a file below and read the notes at the top.
Each folder is one thing you can try.

edit/      move, copy, and remove lines
find/      search and replace
jump/      go to a line, a bracket, or a name
lang/      see colors for each language
server/    format a file and jump to an error
about/     open the page with the duck logo
agent/     ask the assistant to change a file
agent/modes.txt  plan and ask modes, and edits that keep your cursor
agent/tools.txt  let the assistant search, ask the language server, and edit
agent/notice.txt a note when the answer arrives and the panel is closed
agent/size.txt   make the assistant panel taller or shorter
providers/ pick Ollama, LM Studio, OpenAI-compatible, or OpenRouter
reveal/    show this file in the tree
workspace/ open another folder
